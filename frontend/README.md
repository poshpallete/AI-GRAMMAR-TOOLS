# Frontend

The interface is a multi-page HTML, CSS, and JavaScript application.

Start the Flask backend, then run a static server from this directory:

```bash
python -m http.server 5500
```

Open `http://127.0.0.1:5500/`.

The default backend is `http://127.0.0.1:5000`. Change `API_BASE_URL` in `config.js` when using another host.
